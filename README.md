# DSH Store — Hello 测试插件

这是用于 DeepSeek Harness 的第三方测试插件，在支持插件页扩展的版本中提供「DSH Store」标签，展示 `Hi there!`。

在 DSH 桌面版「添加插件」中输入 GitHub 仓库地址：

```text
https://github.com/dshstore/dshstore
```

安装后重启 DSH，在插件页面查看「DSH 商店」。标签和页面接入 DSH 的语言服务，提供中文、英语、俄语、法语、西班牙语、阿拉伯语、日语和韩语翻译；可选择的语言由 DSH 本身及已安装语言包决定，未提供翻译时回退英语。测试版本没有商店功能；旧版本可能没有可用的标签入口。之前安装过 `dsh-store-hello` 的用户应先卸载旧插件，避免同时出现两个标签。

目前本项目尚未发布 npm 包。npm 上的 `dsh-store` 是其他项目，切勿把它当作本项目安装。

这是独立社区项目，与 DeepSeek 官方无隶属关系。
